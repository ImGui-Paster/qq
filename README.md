# CA125 — расписание пар (Flutter)

Один код для iOS и Android — интерфейс идентичен на обеих платформах
(это и есть смысл Flutter: один Dart-код рисует один и тот же UI везде).
Портировано с Android-версии (Java): все экраны, свайп между днями,
редактор звонков, экзамены, ДЗ, поиск, OCR-импорт расписания по фото.

## Структура

- `lib/` — всё приложение (общий код для iOS/Android)
- `android/` — платформенный код + **виджет на рабочий стол**
  (обратный отсчёт до конца/начала пары + текущая/следующая пара)
- `ios/` — платформенный код (без виджета — см. ниже)
- `.github/workflows/dart.yml` — сборка через GitHub Actions

## Сборка через GitHub

Пуш в `main` (или Actions → Run workflow вручную) соберёт:
- `android-apk` — `app-release.apk`, ставится как есть.
- `ios-ipa` — `ca125.ipa`, подписанный через `ldid` (без сертификата
  Apple Developer).

### Важно про `.ipa` без сертификата — честно, как есть

`ldid` не заменяет подпись Apple, а проставляет формальный ad-hoc
формат подписи. Он решает одну конкретную задачу — установка на
**jailbreak-устройство** через AppSync Unified (Cydia/Sileo). На
обычном, не взломанном iPhone такой `.ipa` **не установится напрямую**
— iOS проверяет подпись у настоящего доверенного центра сертификации
при установке, и ldid его не проходит.

Если телефон обычный (не jailbreak), рабочие варианты такие:
1. **AltStore / Sideloadly** — переподписывают `.ipa` твоим Apple ID
   бесплатно прямо на устройстве/компьютере. Можно скормить именно
   этот собранный `ca125.ipa` — они сами перепишут подпись.
   Ограничение бесплатного Apple ID — переустановка раз в 7 дней.
2. **Apple Developer аккаунт ($99/год)** — тогда сборка через
   `flutter build ipa` с настоящим экспортом подписи, работает год,
   можно публиковать в TestFlight/App Store. Могу настроить отдельно,
   если аккаунт появится.

Если телефон jailbreak — собранный `ca125.ipa` ставится через
Filza/AppSync Unified напрямую, без AltStore.

## Виджет на рабочий стол (Android)

Долгое нажатие на рабочем столе → Виджеты → CA125 → «Обратный отсчёт
до конца/начала пары». Показывает большой таймер (сколько осталось
до конца текущей пары, либо до начала следующей), под ним — текущая
и следующая пара. Обновляется раз в минуту (посекундное обновление
виджетов Android не даёт делать штатно — ограничение платформы).
Учитывает изменения в редакторе звонков внутри приложения.

На iOS системного виджета нет — WidgetKit требует отдельный
Swift-extension вне Flutter, можно добавить отдельным шагом позже.

## OCR-распознавание расписания

Настройки → «Загрузить фото». Работает через бесплатный ocr.space
с демо-ключом (`helloworld`, ограничен по частоте запросов). Для
стабильной работы — получи свой ключ на https://ocr.space/ocrapi
и впиши в `lib/logic/config.dart`.
